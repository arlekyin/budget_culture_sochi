# Бюджет-Культура Сочи

Информационная система управления бюджетированием для МКУ «ЦБ УК г. Сочи».

Дипломный проект: «Управление процессом бюджетирования в МКУ «ЦБ УК г. Сочи»»

---

## Стек технологий

- **Backend:** Python 3.11, Django 4.2, Django REST Framework
- **Frontend:** Django Templates, Bootstrap 5, Chart.js
- **База данных:** SQLite (разработка)
- **Экспорт:** openpyxl (Excel)

---

## Роли пользователей

| Роль | Что видит / делает |
|---|---|
| Директор учреждения | Создаёт заявки, добавляет строки расходов, прикрепляет файлы, отправляет в ЦБ |
| Бухгалтер ЦБ | Проверяет заявки, согласовывает/возвращает, вводит кассовые расходы |
| Руководитель | Смотрит аналитический дашборд и диаграммы |
| Администратор | Управляет справочниками, пользователями, лимитами |

---

## Жизненный цикл заявки

```
Черновик → На проверке в ЦБ → Согласована → Включена в бюджет
                            ↓
                  Возвращено на доработку → На проверке в ЦБ (снова)
                            ↓
                         Отклонена
```

## Быстрый старт

### 1. Создание виртуального окружения

```bash
cd budget_culture_sochi
python -m venv venv
venv\Scripts\activate   # Windows
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка окружения

```bash
copy .env.example .env
# Откройте .env и при необходимости измените SECRET_KEY
```

### 4. Миграции

```bash
python manage.py migrate
```

### 5. Загрузка справочников КОСГУ и КВР

```bash
python manage.py seed_classifiers
```

### 6. Создание демо-данных (пользователи + учреждения)

```bash
python manage.py create_demo_data
```

### 7. Запуск сервера

```bash
python manage.py runserver
```

Откройте: http://127.0.0.1:8000

## Структура проекта

```
budget_culture_sochi/
├── config/               # Настройки Django (settings, urls, wsgi)
├── apps/
│   ├── accounts/         # Пользователи, роли, профили
│   ├── institutions/     # Учреждения и лимиты
│   ├── classifiers/      # Справочники КОСГУ и КВР
│   ├── budget_requests/  # Заявки, строки, workflow
│   ├── monitoring/       # Факт, бронирование, дашборды
│   └── reports/          # Сводные отчёты, экспорт Excel
├── templates/            # HTML-шаблоны (Bootstrap 5)
├── static/               # CSS, JS, изображения
└── media/                # Загруженные файлы (сканы)
```
